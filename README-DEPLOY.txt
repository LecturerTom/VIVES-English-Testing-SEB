DEPLOY
1. Extract this archive.
2. Upload these files/folders directly to the GitHub repository ROOT (not the ZIP itself).
3. On GitHub, commit changes. Under Settings > Pages, select Deploy from branch: main / (root).
4. Remove any superseded .seb files from the repo root so students do not launch an older version.
5. Open the site in an ordinary browser (do not test Official SEB at home on a student device).
6. Confirm that the VIVES logo loads and that the practice link works.
7. Confirm that Official links stay hidden until the user opens the "In class only" panel and checks the confirmation box.
8. Verify the complete workflow on Windows, macOS and iPadOS as required.

IMPORTANT
- The website package includes NO teacher-only password record.
- The SEB configuration files are unchanged from the previously supplied tested versions.
- NEVER publish your private teacher credentials file on GitHub, in Toledo or in email.
- For this lecturer's supervised assessments, the SEB exit password is placed in a final-page text block in Toledo. Students are instructed to copy it BEFORE selecting Submit, then to exit SEB only AFTER Toledo confirms submission. 
- A final-page password is visible before submission and can be shared. Supervision mitigates but cannot eliminate this risk. Rotate the Official SEB exit password between different assessments where practical, and do not reuse it as the administrator password.
- In Blackboard Ultra, verify that Prohibit Backtracking is enabled and that the final instruction block appears at the intended point in the assessment using Student Preview or a test student account.
- This public website is not an enforcement mechanism: physically supervise official tests and check that SEB is active.
